Geolocation Test Page

📋 How to test the Location Override extension:

  1. Open DevTools (F12)
  2. Go to the "Location Override" panel
  3. Manual Override: Enable location override and set coordinates
  4. Route Simulation: Upload a KML/GeoJSON/GPX file and start simulation
  5. Click "Start Watching Position" below
  6. For manual override: Change coordinates and click "Apply Override"
  7. For route simulation: Watch coordinates update automatically along the route
  8. Watch how the position updates immediately!

💡 Tip: Watch Position will continuously receive updates. Try both manual override and route simulation to see real-time updates!

🗺️ Sample Files: test-route.geojson, test-route.gpx, and test-route.kml are included for testing route simulation.
